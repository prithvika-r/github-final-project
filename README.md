# Simple Interest Calulator

A simple interest calculator that calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = P × R × T

Where:

- P = Principal amount
- R = Annual rate of interest
- T = Time period in years

## Usage

Run the `simple-interest.sh` script and enter the principal amount, annual rate of interest, and time period.

The calculator will return the simple interest.
